# AI 笔记归档

本 Skill 随小程序源码发布；使用 Python 3 标准库脚本 `scripts/archive.py`，无需安装额外依赖。连接信息保存在本机 `~/.config/ai-note-archive/connections.json`，不要提交或展示完整密钥。

## 关联连接

用户先在小程序「AI 归档密钥」中输入名称并生成密钥，同时取得部署者提供的 HTTPS `archiveNote` URL。运行 `python3 scripts/archive.py link --name <名称> --url <HTTPS地址>`，在隐藏输入提示中录入密钥；自动化环境可用 `--key-stdin` 从标准输入传入。不能把密钥放在命令行参数、仓库文件、最终回答或日志里。一个本机配置可以有多个具名连接。重发密钥后用 `--replace` 更新同名连接。

## 归档对话

1. 运行 `python3 scripts/archive.py list` 查看可选连接。**每次**让用户明确选择目标连接名称，即使只有一个连接。不得从对话上下文猜测目标。
2. 只整理用户指定的当前对话范围。写出简洁标题和 Markdown 正文，保留可核实的见解、结论、待办及必要上下文；不编造来源或共识。不需要复制整段聊天记录。
3. 将拟保存的标题和正文给用户检查，取得明确的归档确认后再写入。若含其他人的隐私或敏感信息，先让用户决定是否保留。
4. 把 Markdown 放入临时文件后运行 `python3 scripts/archive.py archive --name <所选名称> --title <标题> --file <临时文件>`，成功后删除临时文件，报告笔记 ID。也可通过标准输入传正文。不要把正文或密钥作为命令行参数。
5. 若网络请求结果不明，使用错误消息中的请求标识，通过 `--request-id` 重试同一内容，避免普通重试产生重复笔记。不可无限重试；遇到 429 限频提示（每小时 10 篇、每天 50 篇）时告知用户按提示时间后再试，不得换请求标识绕过。

接口仅支持新增笔记。小程序里的普通笔记编辑、分类、搜索和分享照常可用；密钥的撤销与重发在小程序中完成。

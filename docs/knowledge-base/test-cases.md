## 1. 陷阱笔记创建清单（第 0 期 · T0-3）

> 建议直接在小程序里逐篇新建（顺便走真实的保存链路）。标题、正文照抄下表；
> 标签可不选。S 系列刻意与测试搜索词"同义不同字面"，K 系列是精确词兜底考卷。
> S1-S10 覆盖学习/生活/技术三类语料；允许按个人笔记风格微调措辞，但保持设计原则。

### S1（学习）

- **标题**：记词窍门
- **正文**：记词窍门：艾宾浩斯遗忘曲线复习法。人的记忆在学后 20 分钟就掉到一半，按 1 天、2 天、4 天、7 天、15 天的节奏回看，能把留存率拉回来。操作上每次只回看卡壳的词，已经熟练的拉长间隔。
- **将来搜索词**：背单词的方法

### S2（技术）

- **标题**：Redux 读后感
- **正文**：reducer 就像账房先生，管着状态的每一笔进出。任何对 store 的修改都要走它，且必须是纯函数——同样的账目进来，同样的结果出去，不许私自动手脚。dispatch 是递账本的动作，action 是账目摘要。
- **将来搜索词**：redux 怎么管理数据

### S3（生活/技术）

- **标题**：拍照识字功能体验
- **正文**：试了下拍照识字：对着纸质讲义拍一张，两秒钟全部转成可编辑文本，标点和换行基本保留。以后纸质资料不用手动敲了，直接拍完存进笔记再整理。
- **将来搜索词**：OCR 文字识别

### S4（技术）

- **标题**：hooks 初学心得
- **正文**：useEffect 用来处理副作用：订阅、定时器、请求都放这里。依赖数组写什么决定了它什么时候重新执行——写空数组只跑一次，漏写依赖是最常见的 bug 来源。返回的函数会在卸载时做清理。
- **将来搜索词**：副作用处理

### S5（生活）

- **标题**：每天散步半小时的体会
- **正文**：坚持每天散步半小时快一个月了。最大的变化是晚上入睡快了，白天脑子清醒的时间变长。发现饭后半小时出去走最舒服，边走边听点轻的东西，不觉得累。
- **将来搜索词**：运动习惯

### S6（生活）

- **标题**：微信收藏整理
- **正文**：微信收藏文章太多，做了分类整理：按主题建了几个标签，每周日花十五分钟把当周收藏归位，没用的直接删。一个月下来收藏夹终于能看了，找东西不再靠翻。
- **将来搜索词**：信息碎片管理

### S7（学习）

- **标题**：课件归档
- **正文**：把课件拍照转文字存档。整套流程：拍照 → 批量识别 → 校对错字 → 按章节合并成一篇 md 存档。以后复习直接搜文字，不用再翻图片。
- **将来搜索词**：图片转文本

### S8（学习）

- **标题**：八月学习小结
- **正文**：八月学习小结。这个月主要做了三件事：新知识点的首轮学习、错题的复习走查、老笔记的归档整理。复习走查的效果最明显——把之前似懂非懂的部分重新过了一遍，做题正确率明显上来。
- **将来搜索词**：怎么回顾所学

### S9（生活）

- **标题**：家庭账本
- **正文**：账本记录家庭开支。每月月初定预算线，日常每笔支出当天入账，月底按餐饮/交通/日用三类看结构。坚持半年后最大的发现是隐形消费比想象中多，砍掉两项固定浪费后每月能省出不少。
- **将来搜索词**：记账方法

### S10（技术）

- **标题**：Vue 组件通信笔记
- **正文**：Vue 组件之间用 props 传值：父组件绑定属性，子组件声明接收，单向流动。子组件要改只能 $emit 事件让父组件自己改。兄弟组件之间则要找共同父级中转，或干脆上事件总线。
- **将来搜索词**：父子组件通信

### K1（精确词）

- **标题**：授权包装器摘录
- **正文**：withAuth 是本项目 API 层的授权包装器，位于 utils/api-auth.js。签名：withAuth(apiFunction, store, options)。调用前自动检查登录状态，未登录则通过 setLoginModalRef 维护的弹窗引用拉起登录。
- **将来搜索词**：withAuth

### K2（精确词 · 人名）

- **标题**：读书会印象
- **正文**：周五的读书会上认识了岑知远，讲起明清漕运史头头是道，还推荐了三本专著。约好下个月交换书单。
- **将来搜索词**：岑知远

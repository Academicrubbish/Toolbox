# 预览编辑与保存 Spec

## 背景

内容采集阶段获取的文档（OCR 识别结果、链接解析内容、已有笔记引用）可能存在识别偏差、格式不完整或内容冗余等问题。直接将未经确认的内容送入 AI 处理，既浪费 API 调用成本，也可能导致 AI 输出质量下降。

预览编辑环节是整个工作流中的 **Human-in-the-loop** 质量控制点，让用户在 AI 处理前确认和修正内容，确保输入质量。

## 目标

提供文档预览和 Markdown 编辑能力，用户可以查看采集到的内容、修正错误、补充信息，确认无误后保存到学习专区或提交 AI 处理。

## 功能描述

### 用户故事

- 作为学生，我希望在 AI 处理前预览和编辑文档内容，以便修正 OCR 识别错误或删除无关内容
- 作为学生，我希望保存编辑好的文档到学习专区，以便日后随时查看和再次处理
- 作为学生，我希望在编辑时能看到 Markdown 渲染效果，以便确认格式正确

### 功能点列表

#### 文档预览

- 展示采集到的 Markdown 内容，使用 towxml 渲染引擎渲染
- 预览模式为默认展示模式，用户可切换到编辑模式
- 页面顶部显示文档来源标识（笔记引用 / OCR 识别 / 公众号文章）
- OCR 来源的文档额外展示缩略图列表，方便对照原图修正

#### 文档编辑

- 复用现有 `md-editor` 组件，支持 Markdown 编辑和实时预览
- 编辑模式支持常见的 Markdown 语法（标题、列表、加粗、代码块等）
- 编辑内容自动暂存到本地（防止意外退出丢失），页面再次打开时恢复
- 编辑完成后点击"确认"退出编辑模式

#### 文档保存

- 保存时需填写文档标题（OCR 和链接来源自动填入，用户可修改）
- 保存时支持添加标签（复用现有 `dict_category` 标签体系）
- 保存后文档出现在学习专区列表，状态为 `confirmed`
- 已保存的文档可再次进入预览编辑页修改内容

#### 文档状态流转

```
draft（采集后未确认）
  │
  ├── 编辑确认 → confirmed（已保存到学习专区）
  │                  │
  │                  ├── 提交 AI 处理 → processing
  │                  └── 再次编辑 → confirmed
  │
  └── 放弃 → 不创建文档记录
```

### 用例

#### 用例 1：预览并编辑 OCR 识别结果

- **用例名称**：编辑修正 OCR 识别内容
- **前置条件**：用户已完成 OCR 拍照识别，处于预览编辑页
- **操作步骤**：
  1. 预览页展示 OCR 识别的 Markdown 内容
  2. 页面底部展示原始图片缩略图列表
  3. 用户发现某段文字识别有误，点击"编辑"进入编辑模式
  4. 修改错误文字，补充缺失内容
  5. 点击"确认"退出编辑模式
  6. 确认内容无误后，点击"保存文档"
  7. 填写标题（默认使用第一张图片的识别首行），选择标签
  8. 点击"确认保存"
- **预期结果**：
  - 文档保存到 `learn_document` 集合，`status: 'confirmed'`
  - 学习专区列表中出现该文档
  - 原始图片和识别日志保留在 `learn_ocr_log` 中

#### 用例 2：从预览直接提交 AI 处理

- **用例名称**：确认内容后直接 AI 处理
- **前置条件**：用户在预览编辑页确认内容无误
- **操作步骤**：
  1. 用户确认预览内容
  2. 点击"AI 学习处理"按钮
  3. 系统先保存文档（status: 'processing'），再提交 AI 任务
  4. 跳转到 AI 处理结果页
- **预期结果**：
  - 文档自动保存到 `learn_document`，`status: 'processing'`
  - AI 任务进入处理队列

#### 用例 3：编辑已保存的文档

- **用例名称**：重新编辑学习专区中的文档
- **前置条件**：用户在学习专区列表中已保存的文档
- **操作步骤**：
  1. 用户在学习专区列表点击某文档
  2. 进入文档详情页，展示内容
  3. 点击"编辑"进入编辑模式
  4. 修改内容后点击"确认"
  5. 点击"保存"更新文档
- **预期结果**：
  - 文档内容更新，`updateTime` 更新
  - 如果文档已有 AI 处理结果，提示"修改内容后原有 AI 结果将保留，建议重新处理"

## 边界条件

- **暂存恢复**：编辑暂存仅限当前会话，超过 24 小时自动清除
- **空内容保护**：文档内容为空时不可保存，提示"文档内容不能为空"
- **标题必填**：保存时标题不能为空，为空时聚焦到标题输入框
- **大文档处理**：单个文档内容不超过 50,000 字符，超出时提示"内容过长，请精简后重试"
- **游客限制**：游客模式下可预览但不可保存和编辑，点击保存时弹出登录弹窗
- **并发编辑**：同一文档不支持多人同时编辑（单用户产品，无需考虑）

## 验收标准

- [ ] 预览页正确渲染 Markdown 内容（towxml）
- [ ] 预览页顶部展示来源标识（笔记/OCR/链接）
- [ ] OCR 来源的预览页展示原始图片缩略图列表
- [ ] 编辑模式复用 `md-editor` 组件，支持 Markdown 编辑和实时预览
- [ ] 编辑内容暂存到本地，意外退出后可恢复
- [ ] 保存时标题输入框和标签选择正常工作
- [ ] 保存成功后文档出现在学习专区列表
- [ ] 文档标题为空时给出提示并聚焦输入框
- [ ] 文档内容为空时不可保存
- [ ] 游客模式点击保存弹出登录弹窗
- [ ] 已保存文档可再次进入编辑模式修改内容
- [ ] 修改已有 AI 结果的文档时给出提示
- [ ] "AI 学习处理"按钮在预览页和文档详情页均可操作

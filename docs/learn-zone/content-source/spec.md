# 内容采集 Spec

## 背景

学习专区的第一步是解决"内容从哪来"的问题。当前用户的学习资料来源多样：小程序内已有的笔记记录、纸质手写笔记的拍照、微信公众号上的学习文章。现有系统只支持第一种来源，导致大量用户的学习内容无法进入 AI 处理流程。

本子需求提供三种内容采集入口。其中 OCR 拍照和公众号链接解析能力由 [文档新增多来源输入](../multi-source-input/spec.md) 子需求提供，学习专区在此基础之上复用。

## 目标

用户可以通过三种方式将学习内容导入学习专区：从小程序已有笔记中选择引用、通过拍照识别手写/印刷内容、通过微信公众号链接解析文章正文。三种来源获取的内容统一转为 Markdown 格式，进入预览编辑环节。

## 功能描述

### 用户故事

- 作为学生，我希望直接选择小程序里已有的笔记作为学习文档，以便对历史笔记进行 AI 复习和巩固
- 作为学生，我希望拍照上传手写笔记或课本截图，系统能自动识别为可编辑文本，以便省去手动输入的麻烦
- 作为学生，我希望粘贴微信公众号文章链接自动提取正文，以便对网课资料和公众号学习文章进行 AI 处理

### 用例

#### 用例 1：从已有笔记选择

- **用例名称**：导入已有笔记到学习专区
- **前置条件**：用户已登录，系统中至少有一条学习记录
- **操作步骤**：
  1. 用户进入学习专区，点击"新建文档"
  2. 在来源选择页选择"从笔记导入"
  3. 展示用户的笔记列表（复用 record-card 样式），支持按标签和时间筛选
  4. 用户选择一条笔记，点击"确认导入"
  5. 系统读取该笔记的总结内容（summarize.content）
  6. 跳转到预览编辑页，展示笔记内容
- **预期结果**：
  - 笔记内容以 Markdown 格式展示在预览编辑页
  - 文档来源标记为 `source_type: 'note'`，`source_ref` 存储对应 recordId
  - 用户可以继续编辑或直接保存/AI 处理

#### 用例 2：OCR 批量拍照上传

- **用例名称**：拍照识别文档内容
- **前置条件**：用户已登录
- **操作步骤**：
  1. 用户进入学习专区，点击"新建文档"
  2. 在来源选择页选择"拍照识别"
  3. 系统调用 `wx.chooseMedia` 选择/拍摄图片，支持多选（最多 9 张）
  4. 用户确认选图后，展示上传进度
  5. 系统将图片上传至云存储，获取临时 URL
  6. 调用 `processOcr` 云函数，将图片 URL 列表发送给 GLM-4.6V-Flash 视觉模型
  7. GLM 视觉模型逐张识别，返回结构化 Markdown 内容
  8. 系统将多张图片的识别结果按顺序合并为一个 Markdown 文档
  9. 跳转到预览编辑页，展示识别结果
- **预期结果**：
  - 识别结果以 Markdown 格式展示，保留原文的段落结构和标题层级
  - 文档来源标记为 `source_type: 'ocr'`，`source_ref` 存储 OCR 批次 ID
  - 原始图片和识别结果记录在 `learn_ocr_log` 中
  - 用户可以编辑修正识别错误

#### 用例 3：微信公众号链接解析

- **用例名称**：解析微信公众号文章
- **前置条件**：用户已登录
- **操作步骤**：
  1. 用户进入学习专区，点击"新建文档"
  2. 在来源选择页选择"公众号文章"
  3. 系统展示输入框，用户粘贴文章链接
  4. 系统校验链接域名是否为 `mp.weixin.qq.com`
  5. 校验通过后，调用 `parseWechatArticle` 云函数解析文章
  6. 云函数提取文章标题、作者、正文内容，转为 Markdown 格式
  7. 跳转到预览编辑页，展示解析结果
- **预期结果**：
  - 文章标题自动填入文档标题
  - 正文以 Markdown 格式展示，保留图片（图片 URL 替换为云存储永久地址）
  - 文档来源标记为 `source_type: 'link'`，`source_ref` 存储原始链接

### 来源选择页设计

来源选择页展示三个入口卡片，布局如下：

```
┌──────────────────────────────────┐
│         新建学习文档               │
├──────────────────────────────────┤
│  ┌────────┐  ┌────────┐         │
│  │ 📝     │  │ 📷     │         │
│  │从笔记  │  │拍照识别 │         │
│  │导入    │  │        │         │
│  └────────┘  └────────┘         │
│  ┌────────┐                     │
│  │ 🔗     │                     │
│  │公众号  │                     │
│  │文章    │                     │
│  └────────┘                     │
└──────────────────────────────────┘
```

## 边界条件

- **不做通用链接解析**：仅支持 `mp.weixin.qq.com` 域名，其他域名给出"暂不支持该来源"提示
- **OCR 精度兜底**：GLM 视觉模型识别结果可能存在偏差，通过预览编辑环节让用户修正，不承诺 100% 准确
- **OCR 单次上限**：单次最多选择 9 张图片（`wx.chooseMedia` 的 count 参数上限）
- **OCR 单张图片大小限制**：单张图片不超过 10MB（云存储限制）
- **已有笔记选择范围**：仅展示当前用户自己的记录，不包含公共示例记录
- **已有笔记必须有总结内容**：笔记列表中只展示有 summarize 内容的记录，无总结的记录置灰并提示"暂无笔记内容"
- **笔记引用而非复制**：选择已有笔记时，只在 `learn_document` 中存储 `source_ref: recordId`，不复制笔记内容到新集合
- **链接解析超时**：公众号文章解析超时时间设为 30 秒，超时返回错误提示

## 验收标准

- [ ] 来源选择页展示三个入口卡片（从笔记导入、拍照识别、公众号文章）
- [ ] "从笔记导入"可浏览用户的笔记列表，选择后正确加载笔记内容到预览编辑页
- [ ] 无总结内容的记录置灰显示，不可选择
- [ ] "拍照识别"支持从相册选择和相机拍摄，支持 1-9 张图片多选
- [ ] OCR 识别过程中展示进度提示（如"正在识别第 2/5 张..."）
- [ ] OCR 识别结果以 Markdown 格式展示在预览编辑页
- [ ] OCR 识别失败时给出明确错误提示，不阻塞用户操作
- [ ] "公众号文章"输入框支持粘贴链接，自动校验域名
- [ ] 非白名单链接弹出提示"暂不支持该链接，目前仅支持微信公众号文章"
- [ ] 公众号文章解析后标题自动填入，正文正确提取
- [ ] 三种来源的文档均正确标记 `source_type` 和 `source_ref`

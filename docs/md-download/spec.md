## 背景

小程序内文件下载功能受平台限制，现有方案（上传云存储 → 下载到本地 → 保存文件）流程复杂、兼容性差，经常出现下载失败的问题。当前已部署前端网页托管（doc.coptis.top）用于文章分享，可复用该架构实现稳定的下载功能。

## 目标

复用前端网页托管架构，让用户通过"复制链接 → 浏览器打开"的方式下载 Markdown 文档，绕开小程序内文件 API 的限制。

## 功能描述

- 用户在记录详情页点击「下载」，调用云函数存储 Markdown 内容，获取下载链接
- 下载链接自动复制到剪贴板，提示用户"请在浏览器中打开"
- 前端网页 `download.html` 根据链接参数获取内容，自动触发浏览器原生下载 .md 文件
- 下载页面在下载失败时，提供内容预览和手动复制作为兜底方案


## 验收标准

- [ ] 点击下载后，剪贴板获得有效下载链接，提示文案清晰
- [ ] 浏览器打开链接后，自动触发 .md 文件下载，文件名包含标题和时间戳
- [ ] 下载失败时，页面显示内容预览，支持手动复制
- [ ] 云函数正确复用 share_links 集合，share_type 为 download
- [ ] 现有分享功能不受影响

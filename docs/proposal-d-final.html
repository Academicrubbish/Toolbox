核心概念

React Hooks 是 React 16.8 引入的新特性，它允许你在不编写 class 的情况下使用 state 以及其他的 React 特性。

useState 是最基本的 Hook，它接收一个初始值并返回一个状态变量和更新函数：

const [count, setCount] = useState(0);

// 在事件处理器中更新
setCount(prev => prev + 1);

useEffect 用于处理副作用，相当于 class 组件中的 componentDidMount、componentDidUpdate 和 componentWillUnmount 的组合。

闭包陷阱

在使用 useEffect 时，闭包捕获的是渲染时的值，这可能导致状态不同步的问题。解决方案包括使用 useRef 或在依赖数组中正确声明依赖项。

对于复杂的交互场景，useCallback 和 useMemo 可以帮助我们避免不必要的重渲染。
